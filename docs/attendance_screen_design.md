# 勤務実績画面設計

## 位置づけ

本資料は勤務実績画面の構成、状態管理、入力制御、保存、排他、印刷の画面設計を整理する。詳細な項目定義は `attendance_screen_items.md`、UI色ルールは `attendance_ui_guideline.md` を正とする。

本更新は設計書のみであり、実装、ソースコード変更、DB変更、API変更は行わない。

## 設計方針

- 勤務実績画面は業務入力画面であり、対象月の日別実績入力を最短操作で行える構成にする。
- 通常勤務時間は参照のみとし、編集は別画面へ分離する。
- Excel VBA相当の業務チェックはBackendへ集約する。
- Frontendは入力支援、dirty管理、セル強調、エラー一覧表示、印刷表示を担当する。
- 対象月の日数のみ表示し、存在しない日付行は表示しない。
- 作業内容はExcel同様1項目とする。
- 通常勤務は勤務区分ブランクで表現し、初期表示もブランクとする。
- 土日祝日は勤務時間だけ入力されていても勤務区分を必須にしない。

## 画面レイアウト

|領域|配置|内容|
|---|---|---|
|ヘッダ|上部固定|画面名、対象年月、ステータス、保存、提出、編集再開、印刷、合計印刷|
|社員情報|ヘッダ直下|社員番号、氏名、作業場所、所属|
|通常勤務時間|勤務実績一覧上部|適用日、始業、終業、休憩。参照のみ|
|勤務実績一覧|中央|対象月の日数分の日別明細|
|集計欄|一覧下部|総勤務日数、通常出勤、休日出勤、欠勤、有休、総実働、遅刻早退、深夜|
|エラー一覧|上部または下部の固定領域|エラーコード、対象日、対象項目、メッセージ|

## State管理

|状態|管理場所|説明|
|---|---|---|
|rows|Frontend|日別入力値。対象月の日数分のみ|
|dirty|Frontend|未保存変更の有無|
|dirtyRows|Frontend|変更行のみAPI送信用に保持|
|status|Backend正、Frontend表示|draft/validated/submitted/approved/confirmed|
|updatedAt|Backend正、Frontend保持|保存・提出時の排他制御に使用|
|validationResults|Backend正、Frontend表示|エラー一覧とセル強調に使用|
|conflictCells|Backend応答、Frontend表示|排他差分セル|

## 入力制御

|状態|入力制御|
|---|---|
|draft|始業、終業、休憩、勤務区分、作業内容、遅刻早退時間を入力可|
|validated|入力不可。編集再開後にdraftへ戻す|
|submitted|入力不可。編集再開後にdraftへ戻す|
|approved|入力不可|
|confirmed|入力不可|

通常勤務時間、実働、深夜勤務、集計、社員情報、ステータスは常に編集不可とする。

## 保存・dirty制御

- Frontendでdirtyを管理する。
- 入力変更時、対象行をdirtyRowsへ追加する。
- 保存APIには変更行のみ送信する。
- 変更なし行は送信しない。
- 変更行の全入力項目がブランクの場合、FrontendはDELETE指定として送信する。
- Backendは新規をINSERT、既存変更をUPDATE、全入力項目ブランクをDELETEとして差分実施する。
- 保存成功時は成功メッセージを表示し、dirty=false、dirtyRowsをクリアする。
- 対象月変更時にdirty=trueなら確認ダイアログを表示する。
- 確認ダイアログのボタンは「保存して変更」「キャンセル」の2つのみとする。
- 「保存して変更」は変更前月の保存に成功した場合のみ対象月を切り替える。保存失敗時は対象月を変更しない。
- 提出時にdirty=trueなら保存成功後に提出する。

日別レコード削除の判定対象となる入力項目は、その行が保持する始業、終業、休憩、勤務区分、作業内容、遅刻早退時間のすべてとする。出勤日、曜日、休日区分、実働、深夜勤務、集計項目はDELETE判定の入力項目に含めない。

## 排他制御

`updated_at` による楽観的排他制御を行う。

1. 月次取得時に `updatedAt` を保持する。
2. 保存・提出時に `baseUpdatedAt` として送信する。
3. BackendでDB最新 `updated_at` と比較する。
4. 不一致なら排他エラーと最新データ、差分セルを返す。
5. Frontendは入力内容を保持し、最新データとの差分セルのみ黄色表示する。
6. 差分確認後、再編集可能にする。

## エラー表示

- 提出不可時はエラー一覧を表示する。
- 対象セルを赤で強調する。
- 業務警告は橙で表示する。
- 排他差分は黄、dirtyは水色、編集不可は灰色で表示する。
- 色だけに依存せず、アイコン、コード、ツールチップ、一覧へのリンクを併用する。

## 印刷設計

|ボタン|対象|条件|
|---|---|---|
|印刷|月報全体|printable=true、入力エラーなし|
|合計印刷|集計欄のみ|printable=true、入力エラーなし|

Excelの `A40` が空の場合のみ印刷可能という仕様を、WebではBackend算出の `printable` として扱う。
