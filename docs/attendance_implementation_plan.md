# 勤務実績Web移植 実装順序案

## 位置づけ

本資料は勤務実績機能を実装する場合の順序案である。今回の作業では設計書のみ更新し、実装、ソースコード変更、DB変更、API変更、コミット、Pushは行わない。

正本は `docs/9999_勤務表yyyymm（名前）_xxxxx.xlsm`、解析済み `attendance_excel_analysis.md`、`attendance_vba_analysis.md`、および詳細仕様 `attendance_screen_items.md`、`attendance_validation_rules.md`、`attendance_error_codes.md` とする。

## 実装方針

|方針|内容|
|---|---|
|Backend正本|Excel VBA相当の業務ルール、E001-E020、集計、深夜勤務、状態遷移をBackendへ集約|
|Frontend責務|入力支援、dirty管理、変更行送信、エラー一覧、セル強調、印刷表示|
|保存|月単位。入力形式エラーがある場合は保存しない|
|dirty|Frontendで管理。保存成功、提出成功で解除|
|対象月変更|dirty=trueなら確認ダイアログを表示し、「保存して変更」は保存成功時のみ切替、「キャンセル」は切替なし|
|日別削除|変更行の全入力項目がブランクの場合のみDELETE|
|排他|updated_atによる楽観的排他制御|
|通常勤務時間|勤務実績画面では参照のみ。別画面で編集|
|通常勤務|勤務区分ブランクで表現する|
|土日祝日|勤務時間だけ入力されていても勤務区分を必須にしない|

## 実装順序案

### 1. DB

|作業|内容|優先度|
|---|---|---|
|月次ヘッダ|status、updated_at、completion_label、printableを保持|必須|
|日別明細|対象月の日数分の勤務実績を保持|必須|
|勤務区分マスタ|Excel X44:X56相当を保持|必須|
|通常勤務時間|別画面編集用に保持|必須|
|検証結果|E001-E020、警告、対象セルを保持|必須|

### 2. Backend

|作業|内容|優先度|
|---|---|---|
|AttendanceMonthlyService|月次取得、保存、提出、編集再開|必須|
|AttendanceValidationService|E001-E020、勤務区分別判定。E012はVBA有効判定未検出のため推測実装しない|必須|
|HolidayCalendarService|set_calendar相当|必須|
|WorkTimeCalculationService|実働、休憩、単位判定|必須|
|MidnightWorkService|check_midnight_shift相当|必須|
|AttendanceAggregationService|Module1 1500-1530相当の集計|必須|
|排他制御|updated_at比較、差分セル返却|必須|

### 3. Frontend

|作業|内容|優先度|
|---|---|---|
|勤務実績一覧|対象月の日数のみ表示|必須|
|入力支援|時刻形式、勤務区分選択、作業内容補助|必須|
|dirty管理|変更行のみAPI送信。全入力項目ブランク行はDELETE指定|必須|
|対象月変更確認|dirty=true時に「保存して変更」「キャンセル」の確認ダイアログを表示|必須|
|エラー一覧|提出不可時の一覧表示|必須|
|セル強調|赤、橙、黄、水色、灰色とアイコン表示|必須|
|印刷|月報、合計印刷|推奨|

### 4. テスト

|分類|観点|
|---|---|
|Backend単体|E001-E020、休日判定、休憩、深夜勤務、集計|
|API結合|保存、提出、排他、編集再開|
|Frontend単体|dirty、入力制御、状態別ボタン、セル強調|
|受入|ExcelサンプルとWeb計算結果の一致|

## 優先度分類

### 必須

- 月単位保存
- 入力形式エラー時の保存不可
- dirty管理と変更行送信
- 全入力項目ブランク時のDELETE
- 対象月変更時の確認ダイアログ
- updated_at排他制御
- E001-E020提出時チェック
- エラー一覧とセル強調
- 対象月の日数のみ表示
- 作業内容1項目
- 通常勤務の勤務区分ブランク表現
- 土日祝日の勤務区分任意
- 通常勤務時間の別画面編集

### 推奨

- Excel風の印刷レイアウト
- 業務警告とエラーの視覚分離
- 差分セルからの再編集支援

### 対象外

- 週報印刷
- 交通費印刷
- 業務請求明細
- 経費請求シート向けマクロ
