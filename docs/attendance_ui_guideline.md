# 勤務実績UIガイドライン

## 位置づけ

本資料は勤務実績画面全体のUIルールを定義する。Excelのセル色・エラーフラグはWeb UI上の状態表示へ置き換える。色値、アイコン名、ツールチップ文言はWeb UI設計上の候補であり、Excelから直接取得できないため推測を含む。

本更新は設計書のみであり、実装、DB変更、API変更は行わない。

## 色ルール

|用途|背景色|文字色|アイコン|ツールチップ|表示条件|
|---|---|---|---|---|---|
|入力エラー|赤系 `#FDECEC`|`#B42318`|エラーアイコン|`E006: 作業内容が未入力です` のようにコードと内容を表示|入力時補助エラー、保存不可の形式エラー、提出時E001-E020|
|業務警告|橙系 `#FFF4E5`|`#B54708`|警告アイコン|`警告: 実働時間が15分単位ではありません` のように警告内容を表示|VBAの `☆` 相当、`警告` 相当、提出は可能だが確認が必要な状態|
|排他差分|黄系 `#FFF8C5`|`#713F12`|差分アイコン|`他の更新との差分があります。内容を確認してください`|updated_at不一致後、最新データとの差分セルのみ|
|編集中(dirty)|水色系 `#E6F6FF`|`#075985`|編集アイコン|`未保存の変更があります`|Frontendでdirty=true、または変更行|
|編集不可|灰色系 `#F3F4F6`|`#6B7280`|ロックアイコン|`この状態では編集できません`|validated、submitted、approved、confirmed、または権限不足|

## 色だけに依存しない表示

- エラーセルにはエラーアイコンとエラーコードを併記する。
- エラー一覧にはコード、対象日、対象項目、メッセージを表示する。
- セルのツールチップには、エラーコードと短い理由を表示する。
- ボタンの無効状態は色だけでなく `disabled`、ロックアイコン、押下不可理由のツールチップで示す。
- 排他差分は黄色表示に加え、差分一覧またはセル内の差分アイコンで識別できるようにする。
- スクリーンリーダー向けに、エラー数、警告数、未保存件数をテキストで通知する。

## 優先順位

同一セルに複数状態が重なる場合は、以下の順で表示を優先する。

1. 入力エラー
2. 排他差分
3. 業務警告
4. 編集中(dirty)
5. 編集不可

編集不可セルにエラーがある場合、セル背景はエラー色を優先し、入力部品は編集不可として表示する。

## 状態別の見た目

|状態|入力欄|ボタン|セル強調|
|---|---|---|---|
|draft|編集可能。dirty行は水色|保存、提出を表示|入力エラー、dirty、警告を表示|
|validated|編集不可|提出、編集再開、印刷、合計印刷を表示|検証結果のエラーまたは警告を表示|
|submitted|編集不可|編集再開、印刷、合計印刷を表示|提出時結果を表示|
|approved|編集不可|印刷、合計印刷を表示|承認済み結果を表示|
|confirmed|編集不可|印刷、合計印刷を表示|確定済み結果を表示|

## エラー一覧

- 提出不可時は画面上部または下部の固定領域にエラー一覧を表示する。
- エラー一覧の行を選択すると対象セルへフォーカスする。
- セル強調とエラー一覧は同じ検証結果を参照する。
- E001-E020以外の形式エラーは、保存前の入力形式エラーとして別コードまたは文言で表示する。コード体系は推測で増やさず、設計上は「形式エラー」として扱う。
