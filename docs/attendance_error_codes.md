# 勤務実績エラーコード一覧

## 位置づけ

本資料は、Excel `エラーメッセージ一覧` シートと解析済み `attendance_vba_analysis.md` を正として、勤務実績のエラーコード E001-E020 を整理する。

- Excelシート上のメッセージを表示文言の正とする。ただしE009はExcelシート上に定義がないため、Web標準メッセージを採用する。
- Excel VBA `Module1` に存在する判定条件を業務判定の正とする。
- E009 はExcel `エラーメッセージ一覧` シートに存在しないが、VBA `Module1` 1060-1066で欠勤の休日チェックとして使用されている。メッセージは「xx日は休日のため、欠勤を指定できません。」で確定する。
- E012 はVBA `Module1` 1-2248で `MsgNo:E012` の有効判定が未検出のため、推測で条件を追加しない。
- Frontendは入力支援と表示を担当し、Backendを業務ルールの正とする。
- 本更新は設計書のみであり、実装、DB変更、API変更は行わない。

## E009/E010の違い

- E009は、休日（土日・祝日等）に勤務区分「欠勤」を指定した場合の専用エラーとする。メッセージは「xx日は休日のため、欠勤を指定できません。」。
- E010は、休日に休日以外に使用する勤務区分を指定した場合の汎用的な休日区分不整合エラーとする。メッセージはExcel定義の「xx日は休日です。」を維持する。

## 提出不可時の表示

- Backendはエラー配列を返し、提出状態へ遷移しない。
- Frontendはエラー一覧と対象セル強調を同時に表示する。
- エラーセルは赤、業務警告は橙、排他差分は黄、dirtyは水色、編集不可は灰色を用いる。
- 色だけに依存せず、アイコン、エラーコード、メッセージ、ツールチップ、エラー一覧へのリンクを併用する。
